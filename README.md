# Beagle Brain Template — GitHub Pages

Upload `index.html` and `templates/` to the repository root. In Settings → Pages, select `Deploy from a branch`, `main`, `/(root)`.

Place the eight actual ZIP archives in `templates/` with filenames specified in `templates/README.md`. Until uploaded, download links return HTTP 404.

**Citation:** Liu X, Tian R, Zuo Z, Zhao H, Wu L, Zhuo Y, Zhang YQ, Chen L. A high-resolution MRI brain template for adult Beagle. *Magnetic Resonance Imaging.* 2020;68:148–157. https://doi.org/10.1016/j.mri.2020.01.003

**Contact:** zuozt@ibp.ac.cn

Review source terms of use before publishing files. The ZIP archives are not included.
